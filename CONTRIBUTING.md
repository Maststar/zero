# Contributing to Zero

Use Node.js 24 or later. Run `npm test` before and after your change.
Open an issue describing a reproducible bug or a focused feature proposal, then
submit a pull request with the reason for the change, validation and any limits.
Keep changes small enough to review. Include regression tests for game-rule,
privacy, persistence or concurrency changes. Report Android device, OS and
WebView versions for phone-specific problems.

Do not commit signing keys, credentials, player data or private logs. Use your
own development backend and test ads. Preserve third-party notices. Contributions
must be yours to share under the project's MIT license. Be respectful to players
and contributors; discuss the code, not the person.
