# Security

Never include signing keys, service-role keys, passwords, session tokens or player
data in issues or pull requests. Use GitHub's private vulnerability reporting
feature if it is enabled. Otherwise open an issue requesting a private reporting
channel without exploit details or sensitive data. Maintainer response times
are not guaranteed. A source scan and unit tests are not a security audit.

Only the current main branch is maintained. Forks should use their own app
identifiers, signing keys and hosted services.
